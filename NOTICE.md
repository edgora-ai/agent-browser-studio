# Notices

Agent Browser Studio is an open-source browser profile management and automation console built for local use.

## Third-Party Projects and Services

This project depends on open-source packages listed in `package.json`, `package-lock.json`, and the native helper's `go.mod`, including Electron, TypeScript, Vitest, Playwright, ws, marked, electron-builder, and quic-go. It does not depend on a CloakBrowser or RoxyBrowser runtime package.

Review dependency licenses before redistribution. The package metadata declares this project under the MIT License.
