## 第一轮独立审查

审查者 A：同步服务、IPC/preload/renderer、进程检查/恢复锁、凭据分批。审查者 B：ZIP、完整工件和完整传输。
两者均只读审查，不代写修复，不执行真实浏览器、真实凭据、远端或共享构建。

1. **清理祖先替换（已修复，对抗及最终统一回归通过）**：仅见证根与当前目录时，中间祖先可替换后把原后代移回；旧算法在发现祖先变化前会继续删除。现钉住 canonical 外部父链及完整递归栈，每次恢复、删除前重新见证；恢复 hardlink/depth 拒绝。补充中间祖先移回、外部父目录替换与硬链接案例。
2. **凭据转换后重封装（已修复并集成精确证明，最终统一回归通过）**：多个转换文件之间及 reseal 的 await 窗口，允许仅按 changedPaths 授权的成员发生非预期变更。要求传入转换器证明的精确最终 SHA/bytes 和须缺席 sidecar，扫描所得必须匹配后才能 sealing，同时保留最后无回调/await 的见证尾部。不能用另一遍有相同窗口的异步哈希替代。
3. **sidecar 删除续点（已修复，最终统一回归通过）**：异步摘要返回后，调用者须再次校验原路径、祖先和成员身份，才可 unlink。
4. 第一轮服务/权限范围未确认其他新增缺陷。认证先于明文磁盘准入、远端完整读回、同步默认兼容、进程帧不跨 await、原 Promise 清理后结算等边界按源码保持。

- 压缩后归档不再等于原始体积；两个旧批处理测试现用独占合成随机资料，分别采集 capture/prepare 的进度，保留单次 API 内单调性、64 KiB 单次读取、4 MiB 帧上限、逐块守卫、真实让步、精确关 fd、所有字节清零和 lease 结算断言；阶段性 24/24 通过。
- 其中真实失败并非夹具问题：ZIP CRC/元数据等自有临时读取缓冲区缺少 finally 清零，取消后仍有合成明文残留。现已补齐所有权交接及清理，既有取消清零断言通过；不擦除调用者输入或合法返回的独立内容。
- 新增原生压缩器回归确认 Node 26 成功 write callback 可晚于 close，不能仅 await close 就擦除提交的输入。正常取消仍等待真实写回调；原生错误另有会省略 active/queued callback 的路径，不可以强等不存在的通知。
- 进一步 plain-Node 反证确认：先 Abort/destroy、随后原生 Z_DATA_ERROR 时，already-destroyed 分支还会吞掉 error 事件。现只在完全私有的 codec 上包装 public destroy 方法，完整转发 receiver、参数和返回值；只把精确 7 个已知原生 code/errno 配对的调用视为原生 fatal terminal，以幂等 Set 结算遗弃票据。普通 close、无参 destroy、外部 Abort/guard 错误和 ERR_STREAM_DESTROYED 不能放票；所有剩余输入仍待 terminal 与 close 两条件齐备后清零。
- 背压取消只释放至多一个有界 readable slice 后立即 destroy，不为取消完整解压 entry；迟到输出直接清零。真实回归要求 cleanup 新增输出不超过 2 × 64 KiB、取消后没有文件读写、输入在 native completion 前完整而结算后全零，caller 输入不变。
- 原生 fatal 与短 I/O 跨 turn 的第 46 项交叉回归先红后绿：旧实现出错时读计数 135，仍继续至 131141；现在 native input/output drain 在每次 iterator 恢复前同步检查本地 failure，经 steps.return 清除部分分配的缓冲区，fatal 后无新增读写或第二次 codec write。

- 不把 Cookie 等同于全部登录状态，不承诺迁移免登录；不静默将现有完整快照降级为有限同步。
- 未修改真实配置、profiles、历史备份或旧 staging；未自动清理未知遗留物。
- 单个系统调用/fsync、有限的元数据排序/最终见证、Buffer 分配和必要同步 rename/rollback 仍不可抢占。原生等待/真实让步前后必须重新准入，不能把纯读取帧的进程检查摊销率等同于整条链路；没有硬性端到端取消时限或现场吞吐保证。
- 回滚兼容 API 仍同步；丢失运行/恢复 lease 后保留两份材料进入恢复，不对未知状态强行回滚。
