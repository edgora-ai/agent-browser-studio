# 远程部署服务 SKU（#99，99–299 元/次）

## 服务范围

- 远程配好 ≤10 个环境 + 代理绑定 + 时区/语言/ASN 四对齐
- 检测分数验证（ping0 截图交付）
- 交接文档（环境清单 + 代理清单 + 注意事项）

## 客户侧准备清单

- [ ] 远程工具（向日葵/ToDesk）装好并给识别码
- [ ] 代理清单（host/port/user/pass，文本发来）
- [ ] 目标站点清单（要养哪几个号）
- [ ] 1 小时空闲时间（部署+验收）

## 交付检查表（部署方逐项打勾截图）

- [ ] 10 环境全部创建，命名规范（店名/平台/序号）
- [ ] 每环境四对齐截图（IP/时区/语言一致）
- [ ] ping0 检测 ≥90 分截图
- [ ] cookie 备份路径说明已告知
- [ ] 交接文档已发，售后群已拉

## 定价

- 99 元：≤5 环境，标准流程
- 199 元：≤10 环境 + 1 次复查
- 299 元：≤10 环境 + 团队权限配置 + 审计讲解
