## 2. FAQ（Top 8，直接贴群公告）

1. **检测多少分算过？** ≥90 可用；扣分项看 🩺 详情，逐项修（先修红色 high）。
2. ** trial 到期数据会丢吗？** 不会。停建/停启而已，激活后全回来。
3. **换电脑怎么办？** 把设备 ID 发给卖家换换机码；旧机 📦 导出备份，新机 📦 导入。
4. **代理红了（🏭 机房）？** 机房 IP 做号必死，换住宅 IP；正式号前先 Detect。
5. **IP/时区/语言对不上？** 按手册 §14 四对齐检查表逐项改，改完重跑检测。
6. **浏览器启动失败？** 先看报错人话+下一步；常见：代理没起、引擎缺失、指纹漂移被拦（开 🧬 Drift 看）。
7. **误删 profile？** 🗑 回收站 7 天内可恢复；超过 7 天只能用备份。
8. **退款吗？** 未激活可退；激活/下载后不退（激活时已勾选确认）。
