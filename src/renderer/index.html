Create New Profile

Only Name is required — everything else uses defaults. More identity and fingerprint options live under “Advanced configuration”, and you can change them any time from the profile editor.

Firefox engine — launches the installed Firefox with a remote debugging port. Managed fingerprint injection parity is a known follow-up; Firefox profiles currently run in pass-through mode.
Advanced configuration

Pass-through disables seed, platform, locale, timezone, WebRTC, geometry and native fingerprint overrides for stock comparison.

One integer controls GPU, screen, hardware, canvas, audio, fonts — same seed = identical fingerprint.

Advanced hardware fingerprint

Leave empty to let the seed generate coherent hardware. Override only when a risk checker reports a specific mismatch.

Use only with accounts and sites you are authorized for — respect each site's Terms of Service. See ACCEPTABLE_USE.md in the repo.
